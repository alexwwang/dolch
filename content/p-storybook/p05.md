Rain falls down. "Come and play!" said Sam.
{{< /sp >}}

{{< sp image="p/p05/page_02.jpg" page="2" >}}
"**No**," said Ben. "It is **too** wet. I do not want to play."
{{< /sp >}}

{{< sp image="p/p05/page_03.jpg" page="3" >}}

{{< /sp >}}

{{< sp image="p/p05/page_04.jpg" page="4" >}}

{{< /sp >}}

{{< sp image="p/p05/page_05.jpg" page="5" >}}
Sam waits **under** the tree. "**Too** wet! It is **too** cold too!" said Sam.
{{< /sp >}}

{{< sp image="p/p05/page_06.jpg" page="6" >}}
"**What** can we do?" said Sam. "**What** about playing later?"
{{< /sp >}}

{{< sp image="p/p05/page_07.jpg" page="7" >}}
The rain stops. "**Soon** we can go," said Ben. "**Soon**, **no** rain now."
{{< /sp >}}

{{< sp image="p/p05/page_08.jpg" page="8" >}}
"**No** rain now! **Soon** we play!" said Pip.
{{< /sp >}}

{{< sp image="p/p05/page_09.jpg" page="9" >}}
